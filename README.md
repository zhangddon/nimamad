# 自媒体爆款写作智能体（无 API，模拟人工发布）

本项目提供一个可落地的智能体方案，目标是：
- 持续生成高质量、高传播潜力内容；
- 在**不调用平台 API** 的前提下，模拟人工完成发布；
- 支持微信公众号、小红书、百家号等多平台分发；
- 通过内容商业化（广告、带货、私域转化、知识付费）获得收益。

## 1. 总体架构

将智能体拆为 6 个模块，避免“一个大模型做所有事”导致失控：

1. **选题雷达（Topic Radar）**  
   输入：你定义的领域（例如 AI 工具、职场、副业）。  
   输出：候选选题池（按热度、竞争度、变现度排序）。

2. **爆款写作引擎（Writing Engine）**  
   输入：选题 + 平台风格。  
   输出：多版本文稿（公众号长文、小红书种草文、百家号资讯文）。

3. **合规与事实校验（Guardrail）**  
   输入：草稿。  
   输出：风险提示（夸张承诺、违规词、事实不清、侵权风险）+ 修订建议。

4. **素材工坊（Asset Studio）**  
   输入：文稿核心观点。  
   输出：封面文案、配图提示词、摘要、标签、评论引导句。

5. **发布执行器（Human-like Publisher）**  
   输入：最终稿。  
   输出：模拟人工完成粘贴、排版、上传图片、设置标签、定时发布。

6. **复盘优化器（Growth Loop）**  
   输入：阅读、点赞、收藏、完播、转化数据。  
   输出：下周期选题与写作策略更新。

## 2. 无 API 发布：模拟人工的实现思路

> 核心原则：让智能体做“建议与执行辅助”，关键按钮由你确认，降低封号风险。

### 2.1 执行方式

- **浏览器自动化 + 人工确认**：
  - 使用 Playwright / Selenium 在浏览器内执行动作；
  - 自动完成：登录态检测、草稿填充、封面上传、标签建议；
  - 人工完成：最终点击“发布”、异常验证码处理。

- **剪贴板与模板驱动**：
  - 智能体先生成标准化发布包（标题、正文、标签、封面文案）；
  - 一键复制后手动粘贴，避免高频自动化行为。

- **节奏随机化（非常重要）**：
  - 随机等待 1.2~4.8 秒；
  - 分段输入而非一次性注入；
  - 避免固定时间批量同构发布。

### 2.2 风控建议

- 不做“无人值守 24h 全自动发布”；
- 不同平台使用不同文风与标题，避免“机械一稿多投”；
- 登录设备、IP、浏览器指纹保持稳定；
- 每天控制发布频率，逐步爬坡；
- 保留人工审核环节（合规 + 品牌语气 + 发布确认）。

## 3. 平台化内容改写规则

### 3.1 微信公众号（深度）
- 结构：痛点开场 → 案例拆解 → 方法论 → 行动清单；
- 字数：1200~2500；
- 重点：观点密度和可信案例。

### 3.2 小红书（种草）
- 结构：结果先行 + 强场景 + 清单化表达；
- 字数：600~1200；
- 重点：标题冲击力、封面视觉、评论互动钩子。

### 3.3 百家号（资讯/知识）
- 结构：事件背景 → 核心观点 → 延展分析；
- 字数：800~1800；
- 重点：信息增量、关键词覆盖、时效性。

## 4. 智能体提示词模板（可直接用）

### 4.1 爆款选题提示词

```text
你是资深内容增长编辑。请在【AI效率工具】赛道中，基于“高搜索需求 + 中低竞争 + 可商业化”标准，输出10个选题。
每个选题给出：
1) 爆点角度（为什么会被点开）
2) 目标人群
3) 变现路径（广告/咨询/课程/带货）
4) 建议发布平台（公众号/小红书/百家号）
5) 风险提醒（是否涉及夸大承诺、合规风险）
```

### 4.2 多平台改写提示词

```text
将下列原稿改写为3个平台版本：公众号、小红书、百家号。
要求：
- 保持核心观点一致，但文风与结构必须明显差异化；
- 每个平台输出：标题3个、正文1篇、摘要1段、标签5个、评论引导2句；
- 不得使用绝对化承诺词（如“100%”“稳赚”）。
原稿：{{content}}
```

### 4.3 发布前合规审校提示词

```text
你是内容风控审核员。请审查以下文本是否存在：
1) 夸大收益承诺
2) 医疗/金融/法律等敏感领域不当建议
3) 侵权风险（引用、图片、商标）
4) 可能触发平台违规的表达
输出格式：
- 风险等级：高/中/低
- 问题清单
- 必改项
- 可选优化项
```

## 5. 运营闭环（赚钱关键）

1. **周计划**：每周 20 个候选选题，最终发布 7~10 篇；
2. **A/B 测试**：同主题测试不同标题、开头、封面；
3. **数据看板**：记录曝光、点击率、读完率、收藏率、私信率；
4. **转化设计**：每篇内容设置明确 CTA（领取清单、进社群、咨询服务）；
5. **复投机制**：表现好的选题做“系列化 + 多平台矩阵化”。

建议用一个表格管理：
- 列：日期 / 平台 / 选题 / 标题 / 发布时段 / 曝光 / 阅读 / 互动 / 转化 / 复盘结论

---

## 6. 最小可行落地（7天）

- **Day1**：确定细分赛道 + 用户画像 + 变现方式；
- **Day2**：建立 50 个选题池；
- **Day3**：生成 3 平台写作模板；
- **Day4**：完成首批 3 篇并通过合规审校；
- **Day5**：手动+半自动发布到 3 平台；
- **Day6**：收集数据并做首轮优化；
- **Day7**：沉淀 SOP，准备批量生产。

## 7. 注意事项

- 本方案强调内容效率与运营流程，不提供任何违规绕过平台机制的技术；
- 强烈建议保留人工最终确认步骤；
- 在不同平台发布时，请遵守对应社区规范与广告规范。
